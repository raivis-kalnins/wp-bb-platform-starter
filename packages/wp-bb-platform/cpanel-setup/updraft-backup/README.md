# Updraft database backup

Put the current UpdraftPlus database backup here, keeping its original Updraft filename, for example:

`backup_YYYY-MM-DD-HHMM_Site_hash-db.gz`

The cPanel installer copies database archives from this folder into `web/app/updraft/`, ready for **UpdraftPlus → Rescan local folder → Restore database**.

Project backups are excluded from Git by default.
