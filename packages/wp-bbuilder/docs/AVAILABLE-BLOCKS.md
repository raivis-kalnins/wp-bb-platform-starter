# Available WP BBuilder blocks

WP BBuilder registers enabled blocks in the **BBuilder** category.

## Layout

- Row — Bootstrap-oriented row with responsive spacing, gaps, classes, backgrounds, custom SCSS, and a 12-column editor preview.
- Column — responsive XS through XXL widths, quick presets, alignment, spacing, backgrounds, classes, Unique ID, and custom SCSS.
- Section
- Bootstrap Div
- Swiper
- Tabs / Tab Item
- Accordion / Accordion Item

## Content and interface

Button, Card, Cards, CTA Card, CTA Section, Alert, Badge, Breadcrumb, List Group, Navbar, Progress, Spinner, Feature List, Timeline, Code Display, Countdown Timer, Fun Fact, Table, Video, Custom Embed, Inline SVG, and File.

## Forms and data

Dynamic Form, Mailchimp, Login / Register, Ajax Search, Load More, Blog Filter, Catalogue, Events, Testimonials, Price Cards, Contact Links, Booking Calendar, Chart, Google Map, Weather, Name Days, Sitemap, Menu Option, and AI Content.

## Social

Social Follow, Social Share, Social Feeds, and individual feed output.

## ACF

- ACF Hero
- ACF Gallery
- ACF Field — dynamic saved field output from a post / Query Loop item, Options, term, or user / author.

The generic ACF Field block supports automatic, text, image, button/link, embed, and icon display modes. Complex layout fields require purpose-built templates.
