# Changelog

## 0.1.0 - 2026-09-29

- Added Bedrock-style WordPress core separation and environment configuration.
- Targeted WordPress 7.1.2, Acorn 6.x/Laravel 13 and WooCommerce 11.1.2.
- Added Docker/WSL2 local stack with PHP 8.4, MariaDB 11.4, Redis, WP-CLI, Mailpit and phpMyAdmin.
- Added WP BB Platform MU plugin with Acorn bootstrap, system health, safe operations UI and `wp bb` commands.
- Added optional Blade view support to WP BBTheme without removing existing PHP/block-template compatibility.
- Added Blade-first / PHP-fallback rendering for BBuilder ACF Hero and Gallery blocks.
- Added WSL setup, sector installer, licensed ACF Pro installer, deploy checks and release builder.
- Preserved all supplied sector child-theme archives unchanged for compatibility.
- Added cPanel/reseller deployment and large custom-table architecture documentation.
